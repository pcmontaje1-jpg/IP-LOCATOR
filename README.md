# IP-LOCATOR
# 🌍 IP Geolocation Finder

Бесплатный инструмент для определения местоположения по IP адресу.

## Возможности
- ✅ Определение страны, города, региона
- ✅ Информация о провайдере
- ✅ Отображение на карте
- ✅ Определение собственного IP
- ✅ Полностью бесплатно

## Использование
Просто введите IP адрес или нажмите "Определить мой IP"

## Технологии
- HTML/CSS/JavaScript
- Leaflet.js для карт
- ipapi.co API
- GitHub Pages для хостинга
